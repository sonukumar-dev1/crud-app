# crud-app

A simple mini project demonstrating core CRUD (Create, Read, Update, Delete) functionality.

## Features
- **Add:** Create and save new records.
- **Fetch:** View and list existing records.
- **Update:** Edit details of any record.
- **Delete:** Remove records from the system.
